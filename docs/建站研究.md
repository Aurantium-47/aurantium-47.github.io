# 建站研究与复用记录

## 先读既有调研

本次读取了「调研 Codex 额度创意用法」可访问的完整三页记录，并重点重读了个人网站建议、成熟组件选型和个人成果母版。采用了这些已有结论：

- 主体信息易读，手机能顺畅打开，再保留一个有记忆点的互动。
- 将自己的项目持续加入同一个网站，避免每次另建展示页。
- 一个案例保留用途、本人贡献、实现、证据、截图、演示与可公开范围。
- 采用成熟开源底座，复用已有真实作品和媒体。

## 实际复用边界

Astro Nano 来源提交：`66aa017d614828ba5dba02a9e51a1a714850ad31`。移植内容集合结构、PageLayout 与 Head 的元信息组织、FormattedDate、Markdown 静态路由、RSS 聚合方式；保留原始 MIT 许可。没有携带模板的虚构工作经历和示范文章。

本站使用 Astro 内容集合与构建时校验，Markdown 文件生成项目页、随记页与 RSS；项目简介也用于项目简历。照片与正式经历采用简单 JSON。

网页视觉采用青色、橙色、纸面色和编辑式留白；六张海报、巡展视频与独立展馆来自已完成的「涌现图鉴」。站内小标识为本次制作的 SVG。生活相册尚无用户提供的照片。

## 发布与协作

[Astro 官方 GitHub Pages 部署文档](https://docs.astro.build/en/guides/deploy/github/)支持使用 Actions 构建和发布。本站使用用户名仓库，因此网址根路径为 `https://aurantium-47.github.io/`。推送 `main` 触发构建，PR 只进行检查。

[GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)托管静态网站，适合这类个人内容。仓库保存共享状态，dot 与本地任务可以分别读写；GitHub 不自动共享对话的所有记忆，也不会自动唤醒 dot。
